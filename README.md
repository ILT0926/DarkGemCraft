# 暗宝石工艺(DarkGemCraft)
一个Minecraft Fabric模组，添加了新的工具(镐、斧、剑、锄、铲)，合成材料(暗宝石、暗宝石碎片)。
## 支持版本
-Minecraft 1.21.1
-Fabric Loader 0.19.3
## 新增合成配方
-暗宝石碎片通过使用熔炉熔炼黑曜石获得(也支持高炉)，在工作台中9个暗宝石碎片即可合成1的暗宝石
-镐、斧、剑、锄、铲等工具的配方与原版一致，但需注意镐和斧需要暗宝石才可合成
